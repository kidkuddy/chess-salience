the rules (LABELLING.md §2)
  • 2 detected — the square (or a move to/from it) is named and the response attributes a threat, weakness, capture, tactic or opportunity to it.
  • 1 named only — it appears, but only as board transcription, as an item in an undifferentiated list of ideas, or in a statement that dismisses it.
  • 0 absent — never named, in any notation.
  • Board transcription is not detection, however accurate.
  • Dismissal ("c4 is fine") is not detection.
  • Correct square with the wrong reason still counts as detected.
  • Hedged detection ("might be loose") counts.
  • The right vocabulary is not required — "just take on c4 and win a piece" is a 2.
  • Threat or opportunity, either direction, both count.
  • A real tactic found elsewhere while missing the critical square is 0 or 1.
